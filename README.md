## 🇨🇳 中文

面向配音导演与制作方：从一个项目（SaaS 解说、广告、e-learning、有声书、TVC）加品牌与受众上下文出发，产出可交付的 VO brief、经可念性校验的脚本、选声标准、现场导演笔记与结构化补录反馈。核心立场是配音演员不是读稿机器而是演员——要给的是情感语境和「为什么这样说」，不是逐句的抑扬标注。它会先读取工作区里的品牌人格与旧脚本上下文，再用一次打包提问收齐交付物、项目格式、时长与目标字数（约 150 WPM）、品牌人格、目标受众与声音规格，然后按领域规则拟交付物。适合招募并 brief 配音演员、准备现场 session、为品牌选对声音、把拗口脚本改到顺口，以及给已交付的读法写清补录笔记。

### ✨ 能做什么

- 一次打包问完：交付物、项目格式、时长字数、品牌人格、受众、声音规格
- 可念性校验：把适合阅读的书面稿改成适合开口的脚本
- 选角标准：按品牌人格与受众挑声音，不靠感觉
- 现场导演笔记：以「意图」驱动，不给逐句的抑扬标注
- 结构化补录笔记：指明哪一条、哪个词、往哪个方向补
- 先读工作区品牌与旧脚本上下文，减少重复提问

## 🇬🇧 English

For voice directors and producers: starting from a project (SaaS explainer, commercial, e-learning, audiobook, TVC) plus brand and audience context, it delivers a usable VO brief, a speakability-checked script, casting criteria, session direction notes and structured pickup notes. Its stance is that voice talent are actors, not script readers — you give emotional context and the reason behind a line, not line readings. It first reads existing brand-voice and script context from the workspace, then gathers deliverables, project format, runtime and target word count (about 150 WPM), brand personality, audience and voice specs in one packed question before drafting. Use it to hire and brief voice talent, prep a session, pick the right voice for a brand, fix unreadable scripts and write clear pickup notes on a delivered take.

### ✨ What it does

- One packed intake question: deliverable, format, runtime and word count, brand personality, audience, voice specs
- Speakability pass: rewrite copy written for the eye into a script for the mouth
- Casting criteria: choose a voice from brand personality and audience instead of taste
- Session direction notes driven by intent, never by line readings
- Structured pickup notes: which take, which word, which direction to correct
- Reads existing brand-voice and script context from the workspace first to cut repeat questions
